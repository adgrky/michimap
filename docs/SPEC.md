# 道の駅埋め立てマップ(michimap) SPEC

> 基底: 工場マスター(docs/00_master) + シリーズ設計(docs/10_fillmap_series §E, §A3)。本書は差分のみ。

## §1 概要
全国の道の駅1,145駅の訪問記録を地図に「埋めて」いくPOINTモードアプリ。一言: 全国1,145駅、日本一周スタンプラリーをポケットに。

## §2 データ(§E2 POINT / §E6 / §E7)
- ソース: 国土交通省 国土数値情報「道の駅」P35-18(2018年度版・世界測地系)。
- 駅名・所在地・座標は事実データ(著作権対象外)。施設フラグ・写真等は非収載。基準年=2018(年1回更新は手動許容)。
- 前処理: `tools/curate_michimap.py`(GeoJSON→`tools/curated/roadside_stations.csv`)→ `tools/preprocess_point.py`(→`public/data/points.geojson` + `meta.json`)。
- 受入: 1,145フィーチャ / meta.totals.pointCount === 1145・47都道府県。

## §3 塗り状態
- 未訪問(グレー小円) / 訪問済(テーマ色+グロー円+白縁)。visits に存在=訪問済。
- 訪問時アニメ(W1): スタンプ(判子)が落ちる朱色演出(380ms)。prefers-reduced-motion 尊重。
- **クラスタリング**(§E2): 500駅超のため maplibre クラスタ機能を使用。クラスタは点数で可変サイズ、タップでズームイン展開。

## §4 保存(§E4)
- storageKey: `michimap.v1` / version: 1
- visits: `{ [id]: { count, firstDate?, memo? } }`

## §5 画面構成
- タブ: 🗺地図 / 📋リスト(都道府県アコーディオン・ワンタップ訪問 W4) / 📅年表(W5) / ⚙️設定
- 駅タップ→PointSheet: 駅名/訪問トグル/訪問日/回数/メモ140字

## §6 デザイントークン
- アクセント: orange(THEME #fb923c / DIM #fdba74)。未訪問 #3a3f4a。スタンプ朱 #ef4444。クラスタ #475569。

## §7 スコア / 演出(§A3 W2)
- 訪問駅数 / 全国達成率 / 「制覇まであと◯駅」を常時表示。

## §8 達成率
- 全国 = 訪問数/1145。都道府県別達成率を保持(北海道制覇判定に使用)。

## §9 称号
- 道の駅デビュー / 100駅クラブ / 北海道ブロック制覇 / 都道府県横断(20都道府県) / 全国制覇(金)

## §10 シェア画像(§E5)
- 地図スナップ+「道の駅 N/1145駅」+「全国制覇まであと◯駅」+統一フッター。

## 残課題(v2)
- クラスタ円への「済/全」数表示(glyphフォント導入が必要・現状は点数サイズで代替)。
- スタンプ効果音(sound設定はあるが未実装)。地方ブロック別達成率の明示表示。
